# Real-Time Emotion Detection System

## Description
This project detects human emotions in real-time using a webcam. It uses a Convolutional Neural Network (CNN) trained on the FER2013 dataset.

## Features
- Real-time face detection
- Emotion recognition
- Confidence percentage
- CNN-based deep learning model
- OpenCV webcam integration

## Technologies
- Python
- TensorFlow/Keras
- OpenCV
- NumPy

## Dataset
FER2013

## Emotions Detected
- Angry
- Disgust
- Fear
- Happy
- Neutral
- Sad
- Surprise

## How to Run

Train the model:

python train_model.py

Run webcam detection:

python predict_emotion.py
